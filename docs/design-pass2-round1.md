# Design fixes, pass 2 round 1

Shared fixes are implemented in NibDesign and NibContracts. The explicitly requested performance-test change is in FeatPerformanceTests. No build, commit, stash, checkout or reset was run.

- **Dark glass:** Regular glass and its foreground receive the app appearance. Clear's neutral contrast body over registered light paper and Deep's 86% body now sit behind `GlassEffectContainer`, where the combined effect can sample them. Registered droplets use the field silhouettes; static `nibGlass` surfaces inside the container forward their bounds with an anchor preference. Standalone surfaces retain their local underlay. Full-strength labels/icons, the accent-only tint rule, Pencil recede and opaque fallbacks are retained. Resting backdrop canvases are equatable to avoid redraws when another cluster moves.
- **Selection beads:** The shared cover/thumbnail bead has an explicit `onAccent` checkmark on accent. Its unselected state has a white centre and a neutral 2 pt outline in both appearances, including over white covers.
- **Width presets:** The shared `NibWidthPresetButton` now keeps its semantic dot and selected fill colours when glass changes local appearance. Added pixel/layout regressions enforce 5, 8 and 12 pt circles, a 44 pt target and a 40 pt selected cell. **The dash-producing call site remains in feature-owned `NibKit/Sources/FeatPresets/ToolPresetMenu.swift`, outside this job's permitted edits.** [The prepared patch](design-pass2-width-presets.patch) replaces only its thickness slots with the shared button, preserves actions/accessibility/popover anchors, and leaves line-pattern choices as lines. `git apply --check` passed. It has not been applied; the ownership exception requested during the task has not been granted.
- **FractionalIndex:** Unbounded inserts use base-62 boundary counters with logarithmic key growth. Bounded midpoints retain the legacy rule using one iterative byte scan, eliminating recursive suffix copies. Existing stored keys retain their lexical order and need no migration. Batch generation keeps its original compact midpoint distribution. Removed the sole `XCTExpectFailure` in `NibKit/Tests`; the 20 ms × 4 budget is unchanged. The same budget now covers prepends, and the 1,000-key size assertion is tightened from 200 to 4 characters.

Regression coverage was added for long boundary runs, legacy keys, very long shared prefixes, batch/sequential interoperability, selection marker pixels, width dot geometry, glass foreground strength and both kinds of native underlay transport.

Validation: Swift syntax parsing passed; repository lint has zero errors (existing unrelated warnings); focused accessibility lint has zero warnings; whitespace checks passed. An independent Python reference-model check exercised 238,327 valid legacy keys in both directions, all their adjacent intervals, 10,000 random inserts, and 100,000 inserts at each boundary (maximum key length six). This checks the algorithm, not Swift execution speed. Swift runtime tests, the actual 80 ms performance gate and live compositor snapshots remain to be run by the build job, as this task prohibits builds.

The underlay placement follows Apple's [UIGlassContainerEffect documentation](https://developer.apple.com/documentation/uikit/uiglasscontainereffect): the container combines glass effects behind its content view. Nib's neutral contrast exception is specified in DESIGN.md §2.3.
