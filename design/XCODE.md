# CI runner and Xcode

CI must run on `runs-on: macos-26`, the pinned GA arm64 label rather than `macos-latest`, which migrates between images without notice. It must select Xcode 26.6 at `/Applications/Xcode_26.6.app`, either with `sudo xcode-select -s /Applications/Xcode_26.6.app/Contents/Developer` (as `.github/workflows/ios.yml` already does) or with `DEVELOPER_DIR=/Applications/Xcode_26.6.app/Contents/Developer`. Xcode 26.6 (17F113) is the image's default and ships the iOS 26 SDK (26.5), which contains every Liquid Glass symbol NibDesign uses (`glassEffect`, `Glass`, `GlassEffectContainer`, `glassEffectID`). Each of them sits behind `#available(iOS 26.0, *)`, while the deployment target stays iOS 17.0 and the language mode stays Swift 5. The alternatives fail: `macos-15` defaults to Xcode 16.4 with the iOS 18.5 SDK, which has no glass symbols, so NibDesign would not compile; the `xcode-27` image (`/Applications/Xcode_27.0.app`) is a preview outside the SLA that can queue, and building with Xcode 27 also removes the `UIDesignRequiresCompatibility` opt-out, so it belongs only in an optional, non-blocking job. Because NibDesign compiles `Shaders/NibLiquid.metal` into its bundle, and Xcode 26 installs the Metal toolchain as a separate component, add one step to each job right after Xcode is selected: `xcrun metal --version >/dev/null 2>&1 || xcodebuild -downloadComponent MetalToolchain` (it does nothing when the image already has the toolchain).
